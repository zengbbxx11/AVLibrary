# 0.10.0 界面调整

日期：2026-11-16。

- 将原来的大幅标题区缩成工具栏内的当前分类名称，刷新按钮放入工具栏，影片数量继续在底部显示。
- 左侧“个人标签”旁的“管理”打开独立的标签管理，可新增、修改标签和标签分类；左下“演员与厂商”只管理演员、厂商与别名。
- 用应用内标题栏统一外观：空白区域用于拖动与双击最大化，右侧按钮用于最小化、最大化/还原和关闭；关闭仍触发未保存修改提醒。
- 使用自定义标题栏后，Windows 11 鼠标悬停最大化按钮弹出的系统分屏布局菜单未实现。可使用 Windows 系统的键盘分屏快捷键；鼠标拖动、边缘缩放和 Win11 目标电脑仍待实机验证。

## 验证

30 项浏览器界面回归使用命令替身；60 项后端测试、5 项 SQLite 约束和 2 项正式 EXE 隐藏媒体读取场景通过。另使用独立测试构建与真实 Tauri 后端：标签创建、入口分离、最小化、最大化/还原及关闭草稿保护通过。测试构建只用于隔离目录，未进入发布包。详见 verification/native-window-0.10.log。
