# 0.12.0 实现与验收记录

日期：2026-11-16。应用 0.12.0 / 数据库 schema 3。状态：功能实现版，部分实机验收未完成。

**本版按用户确认移除逐帧选图、时间轴和 FFmpeg/FFprobe 配置。** 封面改为 Windows 自动缩略图 + 手动图片/官方封面，相关 D06/T07/T34 按 [需求调整](REQUIREMENTS_UPDATE_0.6.md) 验收。V0.5 原文作为历史基线保留。

## 当前实现

| 范围 | 行为 |
|---|---|
| 三类媒体与本地优先 | 日本/欧美/个人统一入库，扫描不自动刮削，Personal 后端禁止联网元数据任务 |
| 文件与资料 | 稳定 ID、真实改名恢复、外部变化核对、移出忽略/恢复、主文件选择与分回作品 |
| 字幕 | 外挂独立身份、专用根目录、手动优先、替换核查；内嵌轨不再自动检测，明确显示未检测 |
| 封面与属性 | Windows 缩略图和时长/分辨率自动读取；无法取得时占位/未知；手动/官方选图优先，无外部媒体工具配置 |
| UI | 卡片直接播放、编辑抽屉、评分收藏、多选、全库联想定位、组合筛选、保存条件、实体与标签管理 |
| 资料任务 | 手动联网候选核查、修订/人工清空保护、持久任务状态；自动媒体任务去重、超时、取消和进程隔离 |
| 备份与便携 | schema 3、迁移快照、完整资源/哈希校验、恢复前备份；主 ZIP 仅一个 EXE，运行后 app-data |
