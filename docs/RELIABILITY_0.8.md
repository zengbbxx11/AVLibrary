# 0.8.0 可用性与可靠性改进

日期：2026-11-15。数据库 schema 3 保持兼容，主程序包只有一个 EXE；运行时仍在旁边生成 app-data。

## 本轮落实

- 浏览与编辑分开：点击封面播放，点击片名查看详情，详情内可进入编辑；编辑中的文件管理折叠收纳。
- 编辑器保留演员文本原始换行，保存时再拆分名单；关闭原生主窗口时检查未保存资料、设置和管理表单。保存遇到修订冲突时可读取最新版本号并确认保留当前草稿后重试，不静默覆盖。
- 当前筛选显示为可逐项移除的条件；批量管理可查看已选影片。加载失败可重试；移出最后一页最后一部后返回有效页。
- 搜索防抖，复用根目录/标签/任务等辅助数据；后台事件合并刷新。文件变化只触发所属目录扫描，完整周期核对默认 30 分钟，可选 10/30/60/120/1440 分钟。仍是受影响目录内扫描，不是逐文件增量索引。
- 任务按进行中、待核查、失败与中断、历史分组，每页 100 条；旧失败任务不再被最近 200 条历史挤掉。批量资料提交反馈实际排队与跳过数量。
- 字幕候选每页 50 条，可搜索、翻页；可解除绑定并关闭该影片自动匹配，或恢复自动匹配。字幕在原文件上修改时，以文件大小和修改时间核对并要求确认；不是内容哈希，不能识别刻意保留这两项属性的改动。
- 跨目录重新关联同时更新影片和主视频的目录归属；目标未托管时经确认在同一事务中添加目录并关联，失败回滚。目标已属于另一条资料时拒绝覆盖，提示核查重复候选。
- 新增播放器与数据目录检查，检测常见安装位置，提供测试视频及字幕播放；修改播放器设置后可继续原播放请求。测试使用设置草稿，无需先保存；成功提示仅表示已发送启动请求。
- 设置显示数据位置、缓存/封面大小、备份数量；可打开数据目录。清理缓存同时清理不再引用的缩略图，保留人工封面。支持明确恢复系统封面；原人工资产仍保留。
- 定期保留最近 500 条完成/取消的扫描记录；失败记录和自动备份不自动删除。完整核对间隔修改立即生效，界面明确说明。

## 数据和跨机使用

升级前导出备份、退出旧版，替换 EXE 并保留 app-data。schema 3 增加可重建的字幕版本辅助表，旧备份恢复后自动补建，不改变原评分、标签与封面。

迁移电脑请关闭程序后复制 AVLibrary.exe 与整个 app-data；外部视频、字幕和播放器另外复制/安装。若盘符变化，在文件夹管理逐个“重新指定位置”，核查预览再确认。播放器路径需要在新电脑重新检测/选择，随后点击“测试画面与字幕”。目录迁移已有引导，尚非统一的一键迁移向导。

完整备份不包含外部视频/字幕/播放器，也不包含本机 scan-interval.txt 和视图偏好；复制整个 app-data 会带上扫描间隔。新电脑系统媒体组件可能不同，无法读取缩略图时仍可手动导入封面。

## 验证范围

本轮自动化记录见 TESTING.md 和 verification。浏览器 UI 用 Tauri 命令替身验证交互和关闭事件回调，不等同于 Win11 原生窗口、播放器字幕画面的实机验收。

VALID_MEDIA_WORKLOAD.json 使用同一个有效 2 秒无人物 MP4 的 1,000 份副本，执行真实扫描和 10 次正式 EXE 媒体读取；这是有效媒体工作负载基线，不能推断多编码私人视频库、界面滚动帧率或内存占用。

仍待实机验证：另一台 Win11 的完整界面、播放器字幕显示及窗口复用、移动盘/跨卷与不同系统编码组件、真实来源匹配质量。观看状态、完整封面来源历史界面、统一迁移向导和自动备份清理不是本轮已交付功能。
