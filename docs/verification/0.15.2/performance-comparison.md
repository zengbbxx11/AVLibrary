# 映库 0.15.1 与 0.15.2 性能对照

在同一台 Windows 10 x64 机器上，用 Rust release 构建各运行一次 `library_scale_baseline`。每组新建一个独立 SQLite 3.54.1 数据库，用一字节合成文件测量首次扫描，再重复搜索 12 次，每次最多返回 60 部。表中时间单位为毫秒。

| 合成样本 | 0.15.1 首次扫描 | 0.15.2 首次扫描 | 0.15.1 搜索中位数 | 0.15.2 搜索中位数 |
| --- | ---: | ---: | ---: | ---: |
| 100 部影片 | 22.58 | 26.81 | 0.52 | 0.43 |
| 1,000 部影片 | 121.99 | 88.44 | 2.13 | 0.97 |
| 5,000 部影片 | 935.49 | 403.65 | 9.03 | 3.58 |
| 1,000 部影片及 1,000 个字幕 | 205.78 | 167.16 | 3.73 | 2.36 |

这些测量覆盖文件枚举、字幕匹配和 SQLite 查询。首次扫描每组测量一次，100 部样本的扫描耗时在本次测量中上升。封面加载时机与搜索建议请求分开由界面测试验证。
