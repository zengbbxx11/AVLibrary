# 0.7.0 UI 交互调整与验证

日期：2026-11-15。范围经用户明确确认：主要浏览、编辑、标签、筛选、批量、文件夹、播放器、表单与反馈。数据库 schema 保持 3。

## 主要调整

| 原行为 / 问题 | 新行为 |
|---|---|
| “最近活动”旁只有无说明滑块 | 独立“排序”和“卡片大小”控件；最近活动、最近入库、名称、评分、时长；小/中/大；本地记忆选择 |
| 标签新建依赖浏览器 prompt，取消/不可用时没有输入界面 | 管理页新增/编辑表单；可选择分类；影片编辑中输入新标签并“创建并选中”；同名复用；失败保留输入并显示原因 |
| save_tag 忽略 groupId | 同一事务保存名称和分类，先验证分类和重名；改名保持稳定 ID 和影片关联 |
| 组合筛选改动立即生效，“应用”只是关闭 | 独立草稿，应用才提交；取消/Esc 保留原条件；重置和区间检查；保存条件使用应用内命名表单 |
| 关闭影片编辑丢失修改 | 关闭按钮/Esc 需要确认放弃；会影响编辑的文件/封面/字幕操作先询问保存并继续；失败保留草稿 |
| 原生 prompt / confirm 分散 | 命名与确认统一为应用内表单，支持取消、Enter、Esc；焦点限制在最上层弹窗，关闭后恢复；背景不可操作 |
| 连续提交、失败提示短暂消失 | 操作锁、弹窗内禁用重复提交；持续错误提示和进行中状态；扫描期间保留可用的取消入口；取消文件选择不提示成功 |
| 批量类型下拉即写入 | 明确选择数和跨页范围，清空选择；分类明确应用；移出/恢复二次确认数量 |
| 文件夹用途容易混淆、创建后猜测目录 ID | 说明视频和同名字幕可同目录；字幕专用目录可选；用途随创建原子保存；字幕目录隐藏视频分类 |
| 播放器设置专业参数集中 | 解释系统默认程序和字幕能力；清晰程序路径/类型；资料来源折叠为高级设置，新增/移除/调整顺序，启用来源保存前检查必填项 |
| 无搜索结果仍只提示添加文件夹 | 提供清除搜索/筛选并查看全部影片；已移出空列表可返回影片库 |

“最近活动”仍在后台刷新时保留当前卡片位置；显式刷新重新应用活动顺序。其他排序随资料保存重新计算。所有排序在数据库 LIMIT/OFFSET 前执行，未知评分/时长排在末尾，非法排序参数回退为活动顺序。

## 设计参考

- [Notion 数据库属性](https://www.notion.com/help/database-properties)：参考标签/多选属性与集中管理的做法；具体“创建并选中”流程是本项目对标签编辑场景的设计选择。
- [Notion 视图、筛选和排序](https://www.notion.com/help/views-filters-and-sorts)：参考区分筛选和排序。筛选的应用/取消是本项目明确采用的提交方式。
- [WAI 模态对话框规范](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)：参考初始焦点、Tab 循环、Esc、关闭后恢复焦点与背景不可交互。
- 先前查阅 Plex Library View 作为资料库浏览参考；本轮复查该页面返回 403，因此未将其作为唯一验收依据。
