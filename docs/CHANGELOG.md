# 版本变更

## 0.6.1（2026-11-15）

- 新增“诊断与日志”，一键导出单个 JSON 文件，用于另一台电脑的问题反馈。
- 自动记录软件/系统/运行时环境、操作与错误分类/代码；原始报错、参数、路径、片名、笔记和媒体不写入报告，不自动上传。
- 日志轮换、7 天保留、读取时再次校验；启动失败或界面异常时尽量保留自动报告。
- 保留必要的前端代码坐标，开发构建文件单独归档便于排查。
- 新增 9 项后端与 1 项 UI 回归，共 47 项后端、5 项 SQLite、5 项 UI 通过。schema 3 不变，主包仍为单 EXE。

## 0.6.0（2026-11-15）

- 按用户确认删除时间轴、逐帧选图和 FFmpeg/FFprobe 路径配置。
- 扫描后自动读取 Windows 缩略图、时长及分辨率；不支持时占位/未知，保留导入图片与官方封面。
- 旧人工截图和封面保持；旧工具路径忽略，无外部解码工具运行依赖。
- 同 EXE 隐藏子进程隔离系统媒体组件，低并发、超时、取消和源版本校验；相同版本不重复自动尝试。
- 停用/移除目录取消待处理任务，避免后台继续读取。
- 不再探测内嵌字幕轨数，显示未检测；外挂字幕流程不变。
- 主 ZIP 仅 AVLibrary.exe，说明与依赖材料另存文档 ZIP。schema 3 不变。
- 38 项后端、5 项 SQLite、4 项 UI、2 项正式 EXE 原生媒体场景通过。

## 0.5.1（2026-11-14）

- 字幕同一路径被不同文件替换时，保留原绑定并标记待核查；播放前再次核验。重新确认一个作品不会自动确认共用字幕的其他作品。

- 验证：32 项后端（含真实 VFR 生成与选择）、5 项 SQLite 约束、4 项 UI 自动化通过。新增 6 项后端回归与 1 项 UI 回归。
