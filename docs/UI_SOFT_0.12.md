# 0.12.0 浅色柔光外观

日期：2026-11-16。参考用户提供的 design.md，全面采用浅色新拟态外观。

- 使用 #e0e5ec 浅灰基底，统一左上高光与右下柔影；按钮为凸起效果，输入和选中状态为凹陷效果。
- 侧栏、工具栏、影片卡片、筛选、菜单、标签、弹窗、抽屉、设置、提示和窗口栏统一切换到浅色。用户已要求弃用原有毛玻璃，不提供深色切换。
- 以紫色标示选中、主要操作与键盘焦点；失败状态使用可辨认的提示。保留适当文字对比、键盘焦点、禁用状态以及减少动画支持。
- 影片封面仍正常显示，因为它是资料库的核心内容；为可读性，少数边界与错误状态保留轻微区分。
- 本版只改变界面材质与颜色；已有标签、筛选、资料和媒体操作继续使用原有数据。

## 验证

36 项浏览器 UI 测试使用 Tauri 命令替身，覆盖浅色背景、关闭模糊、文字对比、筛选、标签与原有交互。预览截图 0.12-library.png、0.12-filters.png、0.12-settings.png 使用虚构资料；960 宽窗口检查无横向溢出。桌面隔离测试结果见 verification/native-soft-0.12.log。
