# 0.11.0 筛选与界面精简

日期：2026-11-16。

- 去掉资料库工具栏上的显示标题。演员与厂商管理入口移到左侧个人标签下方，仍与标签管理分开。
- 搜索焦点显示单层边框和柔和光晕；排序和卡片大小改为深色菜单，支持鼠标、方向键、回车、Esc 及点击外部关闭，保留原来的排序规则和偏好。
- 筛选在列表上方展开，字幕、评分、时长、标签、演员和厂商分行点选；自定义上下限和常用条件仍可展开。点击应用才更改结果，取消不会应用草稿。
- 标签、演员较多时可以搜索。选择两个以上标签或演员后可切换满足任一/全部。已应用的演员和厂商筛选展示具体名称。
- 旧版常用条件中的空值会归一化，避免显示无效筛选。
- 如果编辑筛选草稿时从侧边栏改变当前筛选，会提示载入最新条件；继续应用旧草稿需要再次确认，避免意外覆盖。
- 直接访问 JavDB 主页在本环境返回 403；本版采用通用的分组筛选思路，并非对该站页面的逐项复刻。

## 验证

浏览器界面自动化使用 Tauri 命令替身，覆盖键盘菜单、筛选应用/取消、冲突保护、大量标签搜索、演员厂商名称和旧流程；隔离桌面筛选程序启动时遇到工具运行授权超时，未取得真实桌面筛选结果；详见 verification/native-filter-0.11.log。Windows 11 的自定义标题栏分屏菜单限制仍与上一版相同。
