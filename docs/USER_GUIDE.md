# 映库 0.12.0 使用指南

0.12.0 采用浅色柔光界面；窗口顶部空白区域可用于拖动，右上角按钮用于最小化、最大化/还原和关闭。Windows 11 鼠标悬停最大化按钮的系统分屏菜单尚未实现。

## 首次运行

将主 ZIP 全部解压到本机可写目录，其中只有 AVLibrary.exe。双击运行，添加媒体根目录、选择日本/欧美/个人片段并扫描。影片卡片先显示，Windows 缩略图和可用时长/分辨率在后台读取。无需配置 FFmpeg/FFprobe。

播放器使用原有设置，可在“播放器与资料来源”选择 PotPlayer/mpv/VLC 或使用系统默认打开。需要 Microsoft WebView2。无法启动时查看原生提示和 app-data/logs/startup-error.log，并确认目录可写、同一目录没有另一实例。

## 封面与媒体信息

自动使用 Windows 提供的视频缩略图，效果通常接近资源管理器，但不保证严格为第一帧。不支持的格式显示占位图；读不到的时长/分辨率显示未知，不用虚假的零值。

卡片编辑菜单可“导入封面图片”或“重新读取系统缩略图”。时间轴与逐帧选图已取消。已有人工图片、人工截图和明确选定的官方封面不会被自动缩略图覆盖。导入图片复制到应用自己的资料目录，不依赖原图之后的位置。

若要放弃当前人工封面，使用“恢复系统封面”并确认；原人工图片资产仍保留。清理缓存会删除不再引用的缩略图，保留人工封面。

内嵌字幕轨数量不再自动探测，显示未检测；外挂字幕选择及外部播放器照常使用。Windows 是否能读取某种编码取决于系统已有媒体组件，失败不会阻止本地索引、评分或播放。系统可能使用自己的缩略图缓存。

## 浏览与编辑

点击封面播放，点击片名查看详情并可进入编辑；评分、收藏、菜单和多选不会误播放。编辑抽屉集中管理资料、字幕、图片、真实改名和打开文件夹。

工具栏“排序”可选最近活动、最近入库、名称、评分或时长；“卡片大小”提供小/中/大。选择会保存在当前电脑的应用视图偏好中。

左侧“个人标签”下方是演员与厂商管理。“个人标签”旁的管理按钮打开标签管理，可新增、编辑和分类；编辑影片时输入标签名称，点击“创建并选中”，再保存影片。同名标签直接复用。关闭未保存的编辑、设置或程序主窗口会提醒，失败时保留输入。

搜索支持番号规范化、标题、演员/别名，可定位并高亮目标；点击“筛选”在列表上方展开分组条件，选择后点击“应用筛选”在全库执行，取消/Esc 保留原条件；支持标签任一/全部、演员厂商、字幕、时长评分区间和保存常用条件。最近活动依据添加和从管理器发起播放记录；后台刷新保持当前网格位置，显式刷新应用新顺序。

多选会显示所选数量，跨页保留；可查看每页 50 部的已选列表并移除单项，翻页按钮固定在底部；“清空选择”可全部取消。批量分类需点击“应用分类”，移出/恢复前确认数量。多选可批量标签、类型、收藏、移出库、手动联网及后台读取缩略图。“移出库”隐藏但保留个人资料与忽略记录，不删除原始视频，后续扫描不自动加回。

## 文件夹与身份

视频和同名字幕可放在同一个文件夹，无需专门拆分。只有字幕单独存放时，添加“字幕专用目录”；它不需要视频默认分类。

扫描不自动联网，默认不跟随目录联接/符号链接。后台监听只扫描发生变化的所属目录，完整周期核对默认 30 分钟，可在设置调整，点击“保存设置”后生效，可手动扫描。取消或离线保留原资料。

停用/移除根目录会停止自动扫描并取消其待处理任务，保留作品资料。重新指定位置或重新关联时核查文件身份；新位置不能与其他登记的影片/字幕目录重叠，包括停用目录。跨卷移动、弱证据或原路径被别的视频替换须人工确认。

真实改名只改同目录视频名并保留扩展名，不隐式改名字幕，不覆盖冲突目标。操作意图先落库，异常后启动核查并恢复关联。同番号重复文件可选主视频或保持为不同作品，不物理删除文件。

## 字幕与播放器

字幕可来自同目录、专用字幕根目录或人工选择。优先保守匹配，歧义由用户选择。人工选择持续保存，同卷改名通过身份追踪。

已选字幕失效或被另一文件替换时，保留绑定并要求核查。弹窗提供设置播放器、重新选择、仅本次无外挂播放、取消；一次性播放不清除绑定。共用字幕的不同作品须分别确认适用性。

系统默认播放器不能统一传入字幕，会提示能力限制。PotPlayer/mpv/VLC 按适配器传参数；实际字幕画面和窗口复用尚未完整验收，详见 IMPLEMENTATION_STATUS.md。启动请求成功不代表已看完。

字幕候选可搜索、每页 50 条翻页。可解除绑定并关闭当前影片的自动匹配，或恢复自动匹配。字幕原地编辑后若大小或修改时间变化，也会要求重新确认。

在设置中可检测常见位置的播放器并使用检测结果，或手动选择。点击“测试画面与字幕（无需保存设置）”后，确认彩色画面和 AV Library subtitle test 字幕均可见；提示已发送请求不等于播放器已正确显示。设置后的保存会继续因默认播放器字幕限制而中断的播放。

## 联网资料

资料来源在设置的“高级资料来源设置”中，可以增删、调整顺序；已启用来源须填写 HTTPS 搜索地址（包含 {query}）和允许域名。不清楚来源配置时可先关闭启用，保留手工管理。

只有明确“获取资料”后才请求网络，候选需人工核查。Personal 由后端禁止进入联网元数据任务，不发送视频、截图、字幕内容或完整本地路径。浏览已有资料、扫描和系统缩略图读取不请求网络元数据来源。

任务中心按进行中、待核查、失败与中断、历史分组，每页 100 条，可取消、暂停领取、重试。异常退出的联网任务需要明确恢复。人工字段、明确清空与新修订受保护，旧结果不能覆盖。来源目前在本环境连接失败，真实匹配质量未验收；可继续手工编辑与使用本地封面。

## 数据、备份和升级

app-data 保存数据库、评分标签、图片和应用缓存，已有资料时保留它。不要把活动数据库放在跨主机网络共享中。

“备份与恢复”导出数据库、设置、个人资料、忽略记录和封面，带 SHA-256 清单；不包含外部视频、字幕、播放器。恢复前校验实际版本、关联及必需图片，再自动保存当前资料副本。当前完整备份使用 schema 3。

升级前备份并退出旧程序，替换 EXE，保留原 app-data；旧工具路径被忽略。软件搬迁时关闭后将整个文件夹连同 app-data 一起复制；媒体也变动时使用重新指定位置。

退出管理器不主动关闭外部播放器。删除软件目录可清理软件自身资料；Windows 系统缩略图/最近使用缓存及外部播放器历史由各自组件管理。

## 诊断与反馈

出问题后进入左侧“诊断与日志”，预览并导出一个 JSON 文件发给协助开发的人。需先使用带日志的新版重现问题，旧版历史无法补录。文件包含环境、操作及错误分类/代码，不包含片名、笔记、完整路径、媒体或数据库，也不会自动上传。无法启动时查看 app-data/logs/latest-diagnostic.json；若没有新文件，再发送错误截图。详见 DIAGNOSTICS_GUIDE.md。

## 在另一台 Windows 11 电脑使用

1. 先备份并退出程序，把 EXE 和整个 app-data 一起复制到新电脑可写目录。
2. 视频、字幕和播放器属于外部文件，需要单独复制/安装；视频和同名字幕可继续放在同一目录。
3. 打开文件夹管理，对盘符或位置改变的目录逐个“重新指定位置”，检查预览后确认，保留原资料。
4. 在设置重新检测或选择播放器，测试画面及字幕。若仍有问题，重现后导出诊断 JSON。

扫描间隔在新版保存设置后纳入完整备份；旧配置兼容 scan-interval.txt。视图偏好仍不包含在完整备份内。实际 Win11/播放器字幕画面仍需在目标电脑验证。

筛选面板中的“自定义范围”可输入评分和时长上下限，“常用条件”可保存和调用组合。标签或演员选择两项以上时可切换满足任一或全部；条目较多时可搜索。
