# 映库 0.9.0 界面更新

日期：2026-11-16。

- 应用内侧边栏、顶部工具栏与弹窗采用半透明磨砂材质、柔和的背景层次和圆角；不支持 backdrop-filter 的环境使用不透明底色。磨砂作用于应用内容区域，不会显示桌面或其他应用的内容。
- 窗口申请 Windows 原生深色主题，标题缩短为“映库”，保留原生窗口装饰、拖动和窗口按钮。窗口外观由系统及辅助功能状态控制。
- 卡片、文字、搜索、导航、标签、表单、操作反馈、弹窗和抽屉统一样式，保留键盘焦点与操作入口。大批量卡片没有逐个应用模糊。
- 支持系统减少动画设置；资源不从互联网加载。

## 验证

28 项浏览器 UI 自动化使用 Tauri 命令替身，覆盖原有设置、标签、筛选、批量、字幕和关闭回调等交互；截图 0.9-library.png、0.9-editor.png、0.9-settings.png 使用虚构资料，仅用于观察网页层设计。60 项后端、5 项 SQLite 测试通过，正式 EXE 的两个无界面媒体读取场景通过。

Windows 10 隔离 EXE 能启动，桌面截图工具两次报 “window capture timed out: timed out waiting on channel”，没有取得标题栏画面，故不能宣称已目视验收原生标题栏。Win11 的标题栏、窗口拖动和不同缩放设置仍需在目标设备检查；此前播放器字幕画面等实机验收范围也保持。
