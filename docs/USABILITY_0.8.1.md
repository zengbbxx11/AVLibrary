# 0.8.1 设置、批量选择与目录迁移改进

日期：2026-11-16。保留单 EXE、免外部媒体工具和 schema 3。

## 用户可见变化

1. 完整目录核对间隔改为设置草稿，与播放器和资料来源一起点击“保存设置”后生效。取消会提醒未保存修改，保存失败保留输入。取消/保存按钮固定在设置弹窗底部，滚动长表单时仍可操作。
2. 查看已选影片改为数据库分页，每次读取 50 部名称和状态，不再逐部获取完整资料。显示已移出库、文件离线状态；可取消单部选择。加载失败可重试，末页删空后自动回退；翻页按钮保持在弹窗底部。
3. 目录重新定位在预览和确认阶段都检查与其他登记目录的重叠，包括父子目录、停用目录和字幕目录；冲突时显示明确错误并保持原关联。位置改变会更新资料修订号，旧编辑草稿不能覆盖新位置。

## 兼容与迁移

扫描间隔现在作为 settings JSON 中的可选 scanMinutes 字段保存，不改变数据库 schema。首次读取旧设置时兼容原 scan-interval.txt；用户保存后以数据库设置为准。新保存的间隔会随完整备份导出、恢复；旧版备份没有此字段时仍使用旧文件或默认 30 分钟。升级无需手工修改文件。

升级前导出备份并退出旧程序，用新版 EXE 替换旧文件，保留整个 app-data。此版不会移动或删除视频与字幕原文件。

## 验证

新增后端回归：间隔旧配置兼容与非法输入不部分保存；已选列表分页、重复/无效 ID、移出与离线状态；目录重叠预览/确认拒绝；真实目录搬迁后笔记、身份保留和过期编辑拒绝。

新增 UI 回归：扫描间隔取消/保存/失败保留；已选列表有界请求、翻页与末页回退；读取失败重试；目录预览失败可见且不发确认请求。截图为浏览器命令替身环境，不作为 Win11 原生窗口或播放器实际字幕验收。

最终证据见 TESTING.md、verification 和 RELEASE_VERIFICATION.json。不同 Win11 电脑、播放器实际字幕显示、移动盘拔插、跨卷和真实来源质量仍沿用既有待验收项。
